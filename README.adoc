= specifications-AA_GLOBAL

Shared infrastructure for building the https://specifications.openehr.org[openEHR specifications^]: global AsciiDoc attributes and boilerplate, reference and bibliography definitions, stylesheets and PDF themes, the publishing scripts, and the Docker image that runs them.

This repository is not a specification. Each `specifications-XX` component repository (RM, AM, BASE, LANG and so on) includes its files, so a change here affects every specification build.

== What is here

[cols="1,3"]
|===
|Path |Contents

|`bin/`
|Publishing and setup scripts. `spec_publish.sh` renders a component's documents with Asciidoctor.

|`docs/boilerplate/`
|Shared AsciiDoc includes: global attributes, style settings, front blocks and the licence block.

|`docs/references/`
|Link attribute definitions (`reference_definitions.adoc`) and the bibliography (`references.bib`).

|`resources/`
|Stylesheets, JavaScript, PDF themes, logos and licence badges.

|`manifest_template.json`
|Template for each component's `manifest.json`.

|`Dockerfile`
|The publishing image. `.github/workflows/docker-publish.yml` builds it and pushes it to `ghcr.io/openehr/asciidoctor` when triggered manually.
|===

== Quick start

Render the HTML of one component, here RM, from the directory that holds all your `specifications-XX` clones:

[source,bash]
----
docker run --rm -u $(id -u):$(id -g) -v "$(pwd):/documents/" ghcr.io/openehr/asciidoctor development RM
----

The output goes to `specifications-RM/docs`.
